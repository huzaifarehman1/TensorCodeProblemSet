# Letter Decoder

## Problem Statement

Your friend has built a neural network that can recognize letters of the English alphabet. After creating the model, they tested it on different letters and saved the network's final outputs.

However, instead of storing the predicted letters directly, the network stores its answers as **output vectors**.

The input to the network is a **one-hot encoded vector** containing 26 values, where each position represents a letter:

```
0 → A
1 → B
2 → C
...
25 → Z
```

A letter is represented by a vector containing all zeros except a single `1` at the position of that letter.

For example:

```
A → [1,0,0,0,...,0]

C → [0,0,1,0,...,0]

Z → [0,0,0,0,...,1]
```

These one-hot vectors are passed through a fixed neural network:

```
Input(26) → Linear(128) → ReLU → Linear(50) → Output(50)
```

The network is created using:

```python
torch.manual_seed(35)
```

This means that the same architecture and random seed will always generate the same model.

Your challenge is to become a **Letter Decoder**. Given the output vector produced by the neural network, determine which original letter created that output.

---

## Input

You are given a CSV file containing the neural network output vectors.

Each row contains 50 values:

```
output_0, output_1, ..., output_49
```

Each vector is generated by passing a single one-hot encoded letter through the neural network.

The model architecture is:

```
26 → Linear(128) → ReLU → Linear(50)
```

The model was created using:

```python
torch.manual_seed(35)
```

---

## Task

Given an output vector from the neural network, find the original letter that produced it.

Your program should generate predictions for all samples while keeping the original order.

---

## Output

Create a submission file containing one column:

- `target`

Each row should contain the position of the decoded letter in the English alphabet.

The mapping is:

```
A → 1
B → 2
C → 3
...
Z → 26
```

Example:

| target |
|--------|
| 3 |
| 1 |
| 26 |

---

## Evaluation

The evaluation metric is:

**Accuracy**

Your predictions will be compared with the hidden correct letter positions.

---

## Submission

After generating predictions:

1. Create a CSV file.
2. Add a column named `target`.
3. Include one integer prediction for every sample.
4. Keep the same order as the input data.
5. Save the file as:

```
submission.csv
```

Example submission:

| target |
|--------|

Upload this file for evaluation.

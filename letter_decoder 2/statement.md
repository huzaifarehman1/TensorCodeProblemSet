# Letter Decoder 2

## Problem Statement

Your friend has upgraded their neural network. Instead of feeding it one-hot encoded letters, they now use a **sparse encoding**.

Each input vector consists of **26 values**, where each position represents a letter of the English alphabet:

```
0 → A
1 → B
2 → C
...
25 → Z
```

Unlike one-hot encoding, **exactly one position is non-zero**, and its value is **always positive**. The magnitude of this value is unknown and may be any positive real number.

For example:

```
A → [7.4, 0, 0, 0, ..., 0]

C → [0, 0, 2.1, 0, ..., 0]

Z → [0, 0, 0, 0, ..., 15.8]
```

The magnitude itself carries no information—the **position of the non-zero element** determines the represented letter.

These vectors are passed through the following fixed neural network:

```
Input(26)
    ↓
Linear(128, bias=False)
    ↓
ReLU
    ↓
Linear(50, bias=False)
    ↓
Output(50)
```

The network was initialized using

```python
torch.manual_seed(35)
```

so the architecture and weights are identical for every sample.

Your challenge is to determine which original letter produced each output vector.

---

## Input

You are given a CSV file containing the neural network output vectors.

Each row contains 50 values:

```
output_0, output_1, ..., output_49
```

Each output vector was generated by passing a sparse input vector through the neural network.

The input vector always satisfies the following properties:

- It contains exactly **26 values**.
- Exactly **one value is non-zero**.
- If the **i-th** element (0-indexed) is non-zero, the input represents the **i-th letter** of the English alphabet.
- The non-zero value is **positive**, but its magnitude is unknown.

---

## Task

For every output vector, determine which letter generated it.

Your prediction should be the **1-indexed position** of the letter:

```
A → 1
B → 2
C → 3
...
Z → 26
```

Generate predictions for all samples while preserving their original order.

---

## Output

Create a CSV file containing one column:

```
target
```

Example:

| target |
|--------|
| 3 |
| 1 |
| 25 |

---

## Evaluation

The evaluation metric is:

**Accuracy**

Your predictions will be compared against the hidden correct labels.
